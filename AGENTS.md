# Project guidelines

Use React, TypeScript, Vite, Tailwind CSS, Motion and Lucide. Keep wedding content in `src/config/wedding.ts`. Keep all assets local and use the `asset` helper for public paths. Respect reduced motion and keyboard users. Never fake successful RSVP submissions. Do not add a backend or tracking without explicit user authorization. Update PLAN.md and run typecheck, lint, tests and build for functional changes. Keep actual credentials out of source control.
